# QuickServe Desktop Update Workflow

## 1) Configure update feed URL
Edit `desktop/update-config.json` and set your hosted update URL:

```json
{
  "provider": "generic",
  "url": "https://updates.yourdomain.com/quickserve/win",
  "channel": "latest",
  "autoDownload": true,
  "checkIntervalMinutes": 240
}
```

This URL must host `latest.yml` plus the installer files generated by `electron-builder`.

## 2) Build Windows installer (NSIS)

```bash
npm run desktop:pack:win:x64
npm run desktop:pack:win:arm64
```

Artifacts are generated under `dist-desktop/`.

## 3) Publish update files to server
Upload all generated files for each release to the update URL location, including:

- `latest.yml`
- `QuickServe-Restaurant-<version>-x64.exe`
- `QuickServe-Restaurant-<version>-arm64.exe`
- blockmap files (if generated)

## 4) Client update behavior
- App checks for updates at launch (after a short delay) and every configured interval.
- If update is available, user sees notification.
- After download, user is prompted to restart and install.

## 5) Versioning rule
Always bump `package.json` version before creating a release.

## 6) Code signing (recommended)
For production deployment, sign Windows installers to reduce SmartScreen warnings.
